# Homebrew tap

```sh
brew trust --cask robbyczgw-cla/tap/activity-plus
brew install robbyczgw-cla/tap/activity-plus
```

Homebrew only loads casks from taps you have trusted, hence the first line.

| Cask | App |
|---|---|
| `activity-plus` | [Activity+](https://activityplus.xyz), a macOS system monitor that shows which app is responsible for the load. Apple silicon, macOS 15 or later. |

Activity+ updates itself; `brew upgrade` is not needed for new versions.
